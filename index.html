5-Whys Root Cause Analysis (RCA)

  1. Why did the burst occur? Public SSH port was reachable by external scanners.
  2. Why was password auth probed? Attackers attempted automated password spraying.
  3. Why were no accounts compromised? PasswordAuthentication was already disabled; Ed25519 keys enforced.
  4. Why was auto-firewalling triggered? Sentinel Daemon intercepted the auth flood before log saturation.
  5. Root Cause: Default internet-facing port exposed to automated reconnaissance; mitigated by zero-trust bastion isolation.

Corrective & Preventive Actions (CAPA)

  • Automated Kernel Drops: Deployed Sentinel Daemon with 1-hour rolling TTL blocklist.
  • CI/CD SSH Hardening Hook: Pre-commit validation preventing PasswordAuthentication yes in git.
  • Threat Intel Sync: Automated daily sync against AlienVault OTX and AbuseIPDB feeds.
  • Zero-Trust Bastion: Moved all management interfaces behind private WireGuard mesh.

STRIDEThreatMitigation in Sentinel DaemonResidual Risk
SpoofingAttacker spoofs a source IP in log entries to frame a legitimate host and get it blocked.Daemon reads IPs from the kernel-level auth log, not user-controllable input.An attacker with log-write access could still forge entries.
TamperingLocal attacker modifies the block-list or auth.log to erase evidence or unblock their IP.Dedicated low-privilege systemd service with restricted state-file permissions.Block-list writes aren't cryptographically signed yet.
RepudiationNo audit trail proving which IP was blocked, when, and why.Every block logged with timestamp, matched pattern, and rule applied.Logs are local-only — no central tamper-evident store yet.
Info DisclosureDaemon logs could leak defensive posture to an attacker with read access.State file restricted to service user; no secrets ever written to logs.Verbosity not reviewed under an assume-breach scenario.
Denial of ServiceFlooding auth.log or triggering mass false blocks against shared IPs.Rolling-window correlation; bounded regex matching to avoid backtracking; every block carries a TTL and auto-expires.No allowlist for known shared-IP ranges yet — top fix for v2.
ElevationA bug in iptables invocation could run arbitrary commands with privilege.Narrowly scoped helper with fixed command template; no shell concatenation.Privilege boundary not independently audited yet.
